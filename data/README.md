# data

AI TA 執行時用的資料，是給模型讀的。研究資料放 `research/`，不放這裡。

| 資料夾 | 放什麼 | 公開 |
|---|---|---|
| `knowledge/` | 課程知識清單：要讀哪些講義和筆記、檔案在哪裡。原檔留在 `Machine Learning/Week*/`、`Machine Learning/Midterm Review/`，不複製進來 | 是（只有清單） |
| `index/` | 切段與向量索引，可以從 `knowledge/` 重建 | 否 |
| `learner/` | 個人作答紀錄與弱點 | 否 |

課程講義是教授的教材，不放進 repo。
