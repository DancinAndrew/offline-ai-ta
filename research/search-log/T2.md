## arXiv API｜批次查 21 篇 T2 候選的摘要（2026-11-11）

用 `export.arxiv.org/api/query?id_list=…` 一次取回標題、作者、摘要、作者註記的刊登處。刊登處另外用 OpenReview API 或 ACL Anthology 確認的，標在括號裡。

- 留（篩選）：**Lost in the Middle**（Liu et al., TACL 2023；2307.03172）。長上下文中間的資訊容易被忽略，支持「段數少、重要的放前面」
- 留（篩選）：**Self-RAG**（Asai et al., ICLR 2024 oral，OpenReview 確認；2310.11511）。模型自己決定要不要檢索並自我批評；要用特殊 token 重新訓練，對 qwen3.5:9b 不能直接用，只借概念
- 留（篩選）：**Corrective RAG**（Yan et al., arXiv 2401.15884）。先評估檢索品質再決定修正；它的退路是上網搜尋，離線用不到
- 留（篩選）：**HyDE**（Gao et al., ACL 2023，2023.acl-long.99）。先寫假想答案再檢索；在本機要多呼叫一次 9B，列為選配
- 留（篩選）：**Chain-of-Note**（Yu et al., EMNLP 2024；2311.09210）。先為每段寫閱讀筆記，判斷相不相關，處理無關段落
- 留（篩選）：**Trust-Align**（Song et al., ICLR 2025 oral；2409.11242）。衡量 RAG 中「該拒答時拒答、出處有依據」；對 T6 的微調選項有參考價值
- 留（篩選）：**Qwen3 Embedding**（Zhang et al., arXiv 2506.05176；技術報告，B）。Ollama 有 0.6b／4b／8b，含 reranker 但 Ollama 沒有 rerank 端點
- 留（篩選）：**Is Semantic Chunking Worth the Computational Cost?**（Qu et al., Findings NAACL 2025，2025.findings-naacl.114）。摘要：語意切段的成本沒有換到一致的效果。支持先用簡單、結構化的切法
- 留（篩選）：**Searching for Best Practices in RAG**（Wang et al., EMNLP 2024，2024.emnlp-main.981）。逐環節比較切段、檢索、重排序；之後設計實驗時可以參照
- 留（篩選）：**RGB**（Chen et al., AAAI 2024；2309.01431）。中英文 RAG 基準，測雜訊、拒答、整合、反事實四種能力；「該拒答」是 T2 降低編造的核心
- 留（篩選）：**CRUD-RAG**（Lyu et al., arXiv 2401.17043）。中文 RAG 基準，新聞領域、簡體
- 留（篩選）：**Evaluating Verifiability in Generative Search Engines**（Liu et al., Findings EMNLP 2023；2304.09848）。出處召回／精確率的人工稽核，和 ALCE 互補
- 留（篩選）：**Making RALMs Robust to Irrelevant Context**（Yoran et al., ICLR 2024 poster，OpenReview 確認；2310.01558）。用 NLI 過濾無關段落，或用訓練讓模型不被干擾
- 留（篩選）：**RAG**（Lewis et al., NeurIPS 2020；2005.11401）。RAG 的原始論文，當背景
- 刪：**RAGAS**（2309.15217）。屬於評估工具，交給 T8
- 刪：**LongCite**（2409.02897）。長上下文逐句引用，要訓練；我們不走長上下文
- 刪：**RAPTOR**（ICLR 2024 poster；2401.18059）。用 LLM 遞迴摘要建樹，建索引成本高；筆記本身已有階層
- 刪：**Late Chunking**（2409.04701）。需要嵌入模型的逐 token 向量，Ollama API 只回傳一個向量，做不到
- 刪：**MiniRAG**（2501.06713）。小模型 RAG 用異質圖，複雜度高、證據只有作者自測
- 另外留 C-Pack、MMTEB（見上一節）
