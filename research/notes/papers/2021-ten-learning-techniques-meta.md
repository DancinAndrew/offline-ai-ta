## 一句話

把 Dunlosky 等人（2013）評過的 10 種讀書技巧做成後設分析：**分散練習**（d = 0.85）和**練習測驗**（d = 0.74）效果最大，重讀、畫線、摘要最小（約 0.44–0.47）。但大部分研究測的是「表層記憶、馬上測、近遷移」，對深層理解的證據少很多。

## 他們怎麼做

- **起點**：Dunlosky 等人 2013 年的綜述（Psychological Science in the Public Interest）把 10 種技巧分成高、中、低效用，但沒有算效果量。這篇補上統計合併。
- **資料**：242 個研究、1,619 個效果量、169,179 名受試者。
- **分析的條件**：學習領域、近遷移或遠遷移、表層或深層學習、年級、能力、延遲多久才測、期刊影響力。
  - **近遷移**：測驗和練習的任務很像；**遠遷移**：要用到不同情境。
  - **表層學習**：記住事實；**深層學習**：理解關係、能解釋和應用。

## 證據

- **10 種技巧的效果量**（表 1，隨機效果模型）：

  | 技巧 | Dunlosky 分級 | d |
  |---|---|---|
  | 分散練習（distributed practice） | 高 | 0.85 |
  | 練習測驗（practice testing） | 高 | 0.74 |
  | 精緻化詢問（elaborative interrogation，問自己「為什麼」） | 中 | 0.56 |
  | 心像（imagery） | 中 | 0.56 |
  | 自我解釋（self-explanation） | 中 | 0.54 |
  | 記憶術（mnemonics） | 低 | 0.50 |
  | 重讀（re-reading） | 低 | 0.47 |
  | 交錯練習（interleaved practice） | 低 | 0.47 |
  | 畫線（underlining） | 低 | 0.44 |
  | 摘要（summarization） | 低 | 0.44 |

- **整體平均** d = 0.56。作者認為「低」的技巧也不是無效，只是相對較弱；高中低的切點有任意性（例如記憶術 0.50 和自我解釋 0.54 很接近）。
- **表層 vs. 深層**：表層學習 d = 0.60，深層學習只有 d = 0.26（深層的效果量只有 109 個）。
- **近遷移 vs. 遠遷移**：近遷移 d = 0.61，遠遷移 d = 0.39。
- **延遲**：68% 的效果是在一天內（通常是馬上）測的；延遲到 1–6 個月的效果量只有 64 個，平均 d = 0.51。
- 作者的結論：「大部分研究是表層學習、馬上測、只測近遷移」，不能直接推論到深層理解與遠遷移。

## 對 AI TA：可以借用／不適用

- **可以借用：複習流程以「考自己」和「分散複習」為主軸**，重讀筆記只是輔助。這和 IES 實務指南（[2007-ies-organizing-instruction](2007-ies-organizing-instruction.md)）的結論一致。
- **可以借用：「為什麼」和「自我解釋」題當第二層**。效果中等，但比較接近機器學習課需要的理解（推論）。
- **要保守：深層理解的證據弱**。機器學習的期中內容（貝氏、決策樹、資訊增益）多屬概念理解。效果量不能直接拿來預估 AI TA 的成效，評估時要另外量（見 T8）。

## 限制與疑點

- 這篇的作者包括 Hattie；和 Dunlosky 2013 的研究範圍重疊很多（同一批技巧），不完全獨立。
- 分散練習的受試者人數（152,952）集中在少數大型研究，平均值可能被少數研究主導。
- 原文的近遷移和遠遷移樣本數寫成 N = 197 與 N = 1,385，和「遠遷移很少」的敘述矛盾，可能是筆誤；這裡只引用 d 值。
- Dunlosky 2013 原文的出版社網站擋自動下載（HTTP 403），沒有讀到全文，只看了摘要與 APS 的說明頁；這篇是替代的精讀來源。
