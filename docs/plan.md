# AI TA 專案規劃

> 版本 3（2026-11-11）。只排順序、不排日期：每一步完成、我確認後才做下一步。研究怎麼做見 [research/README.md](../research/README.md)，課程端的要求見 [course-requirements.md](course-requirements.md)。

## 1. 目標

### 1.1 一句話

做一個**能離線使用的課程複習 AI 助教**。它跑在本機的 qwen3.5:9b 上，根據我自己的講義和筆記回答問題並附上出處，會出題、批改、記住我哪裡不會，並以 agent 的形式帶我走完一段複習。開發和驗證都先用**期中考範圍**的內容。

### 1.2 情境

- **我真的用過**：期中考前在飛機上沒網路，我用 qwen3.5:9b 問問題。答案看得懂但不滿意，而且當時沒做任何調整。
- **用期中範圍反覆練習**：這門課沒有期末考，所以拿期中考範圍反覆練習。這些內容既是學習素材，也是評估素材。
- **其他情境不適合**：寫作業、Lab 和 AI Cup 需要大量寫程式和上網查資料，9B 本地模型不適合當主力。

### 1.3 服務對象

| 對象 | 要什麼 | 對規劃的影響 |
|---|---|---|
| 我自己 | 複習得更好 | 以複習流程為主；斷網一定要能用 |
| 對外展示（教授、作品集） | 看得到想法、方法和建置過程 | 研究有出處和分級；決策留紀錄；有評估數字和展示；對外文件有英文版 |
| 課程評分 | How to train AI TA 15%、AI 互動紀錄 | 過程完整保存；`records/` 只新增、不修改 |

### 1.4 核心假設（要靠評估驗證，不是已知事實）

> 在「有範圍、有講義」的考試型複習任務上，9B 本地模型加上設計良好的 harness（提示詞、工具、記憶、流程），可以接近 frontier 模型的表現。

驗證方式：用同一組題目比較三種設定。

1. **裸模型**：就是我在飛機上的用法，當基準線（baseline）。
2. **AI TA**：qwen3.5:9b 加上這個專案的 harness。
3. **Frontier 模型**：給它同樣的講義，當上限參考。只在評估時使用，AI TA 執行時不依賴它。

### 1.5 範圍

- **現在做**：複習問答（附出處）、出題與批改、弱點追蹤、agent、介面、評估。
- **AI TA 完成後才做**：拿它去協助 AI Cup。
- **先不管**：期末專題、AI Cup 解法本身（在 `../AICUP2026/`）。

### 1.6 限制

- **本地模型**：Ollama 跑 qwen3.5:9b（見 [decisions/0001](decisions/0001-base-model-qwen3.5-9b.md)）。
- **離線**：執行時完全不需要網路。模型、嵌入模型、索引、介面用到的檔案都在本機。
- **個人化**：用我的講義、筆記和作答紀錄。
- **機器**：Apple M5、32 GB。
- **公開 repo**：互動紀錄、個人作答資料、論文 PDF、課程講義都不公開（見 2.2）。
- **文件語言**：
  - 自己看的文件用繁體中文。
  - 對外文件（`README.md`、`reports/`）英文、中文各一份。
  - 給 AI 工具看的 `CLAUDE.md` 用英文。
- **檔名**：只用英文、數字、連字號。GitHub 網址才不會變成亂碼；內容照上面的語言規則。

**流程**：research → 討論 → docs → dev → 評估 → reports。records 收錄整個過程。

### 2.1 放置規則

1. **research 和 data 分開**：research 給我看，內容是「怎麼做 AI TA」；data 給模型讀，內容是「課程知識和我的作答」。例如，講怎麼做 RAG 的論文放 research；教授指定讀的 Transformer 論文放 data。
2. **docs 和 reports 分開**：docs 是內部工作文件，可以隨時改；reports 是給別人看的定稿。
3. **各區不混放**：研究區不放程式，開發區不放研究筆記，records 只新增。
4. **講義不複製**：原檔留在 `Machine Learning/Week*/`、`Machine Learning/Midterm Review/`，`data/knowledge/` 只放清單。

### 2.2 不公開的東西

| 路徑 | 為什麼不公開 |
|---|---|
| `records/` | 互動紀錄含個人資訊與完整對話；課程要交給教授，不需要公開 |
| `data/learner/` | 個人作答紀錄 |
| `research/pdfs/` | 論文著作權屬於作者或出版社；筆記裡附原始連結 |
| `data/index/` | 可以重建；也可能含講義原文片段 |
| 課程講義 | 本來就不在 repo 裡 |

從講義或練習題直接摘錄的評估題，到開發階段再決定放哪裡；預設不公開。
