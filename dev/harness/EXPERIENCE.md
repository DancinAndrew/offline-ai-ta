# Harness 改良紀錄

照 harness2 的做法：一次只改一個元件，用同一組題目重跑，比較行為後，有證據才保留。每一輪的設定和逐題結果在 `dev/eval/runs/`。

## 方法與限制

- **題組**：`dev/eval/midterm-baseline.jsonl` 的 16 題。參考答案還是 Claude 起草的版本，還沒經過我核對。
- **評分**：Claude 當輔助評審做初評，逐題對照參考要點，分成正確、部分正確、錯誤三級。依決策紀錄 0003，最終分數以我的盲評為準。
- **固定種子仍無法完全重現**：從 R0 起固定 `seed: 7`，但提示完全相同的題目，兩輪的回答仍然不同（例如 R1 和 R2 的 mb-06、mb-07）。所以只有目標題上整類行為翻轉的改變才算數；其他題 ±1 級的變化當作雜訊。
- **延遲受機器狀態影響**：R1 起同樣長度的回答產生得比較慢（每秒 15.1 → 8.9 token），可能和連續推論一小時有關。正式的延遲比較留到第 7 步，冷卻後交錯執行各設定。

## 改動 1：先判斷題型，計算交給 Python（採用）

- **目標失敗**：mb-17。熵的計算題檢索到另一題的段落，模型拿段落裡的數字湊出 1.62 或 1.446；正確是 0.971，基準線反而答對。
- **改動**：
  - 新增一次結構化呼叫判斷題型（`skills/route/SKILL.md`）。
  - 計算題由模型寫出 Python 算式，交給限制過的計算器（`dev/src/ai_ta/calc.py`）算，結果當成第 [1] 段「程式計算結果」。
- **結果**：mb-17 從錯誤變成正確，算式和數值都對。題型判斷和我的標記在 14 題中有 11 題一致，判錯的是 mb-05、mb-13（被判成確認理解）和 mb-19；這 3 題的回答沒有變差。題型判斷本身每題多約 2.1 秒（中位數）。
- **教訓**：能由程式確定的事，交給程式最可靠，這是 harness2 說的「腳本」元件。

## 改動 2：確認理解拆成獨立的逐點判斷（採用）

- **目標失敗**：mb-08、mb-16。使用者說出有錯的理解，模型回答「完全正確」或「基本正確」；基準線也一樣。
- **改動**：
  - 題型判斷時，先把使用者的說法拆成幾個主張。
  - 每個主張各自檢索。
  - 用一次結構化呼叫逐點判斷：正確、需要修正、錯誤、筆記沒寫。
  - 程式把判斷結果排成回答（`skills/check/SKILL.md`）。
- **結果**：
  - mb-08 從錯誤變成正確：「P(B) 是新的條件」被判成「需要修正」，並寫出正確說法「證據機率」。
  - mb-16 沒修好：它把「不重複選特徵」判成「對」，還編了理由。877 字、77 秒，太長也太慢。
  - mb-09 的總結句和逐點判斷互相矛盾。
- **教訓**：判斷拆開以後，證據明確時就不會順著說；但證據沒被檢索到時，判斷還是會錯。這時瓶頸在檢索，不在判斷。

## 改動 3：護欄擋編造的規則和數字；確認理解變短（採用）

- **目標失敗**：
  - mb-14、mb-15、mb-16 一直加上筆記沒寫的「特徵不能重複使用」。
  - mb-11 在初版自己編了一個數字例子，還算錯。
  - 改動 2 帶來的問題：mb-16 太長、mb-09 總結句矛盾。
- **改動**：
  - `guardrails.md`：不要推出段落沒寫的一般規則；不要自己編數字例子。
  - `skills/check/SKILL.md`：一般規則要有段落明確寫出才能判對；修正說明只寫一句；總結要和逐點判斷一致。
  - `skills/route/SKILL.md`：主張最多 4 項。
- **結果**：
  - mb-16 從錯誤變成部分正確：抓到了「特徵相同、標籤不同時切不乾淨」和「筆記沒說不能重複使用特徵」兩個關鍵誤解；但把「防止過擬合」說成無關，這點判錯了。仍然有 647 字、63 秒。
  - mb-14 從錯誤變成部分正確。
  - mb-09 的總結句恢復一致。
  - 錯誤從 2 題變成 0 題。
- **教訓**：把禁止事項寫得具體（舉出「不能重複使用」這種例子），比籠統的「只根據段落」有效。

## 還沒解決的問題

- **mb-06**：筆記裡有「小學生版」的比喻，但沒被檢索到；R3 改成誠實地說「筆記未提供小學生比喻」。這是檢索問題。
- **mb-07**：模型一直認為正規化能「修正」分類結果。筆記明寫分類只要比大小，這是模型原有的誤解。
- **mb-13**：沒有說明 CART 一律二元切分，因為講三種演算法比較的那一節沒被檢索到。
- **mb-15、mb-16 太長也太慢**：48–63 秒、577–647 字。單題已經超過 40 秒，只是中位數還在門檻內。
- **題型判斷會打斷快取**：判斷題型和寫回答用的是不同的系統提示，Ollama 沒辦法重複使用上一次的提示快取。
