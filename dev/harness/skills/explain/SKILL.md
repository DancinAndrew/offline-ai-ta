# 解釋模式

1. 判斷問題的類型：概念、比較、計算、公式解讀、事實，或「確認理解」（使用者先說自己的理解，再問對不對）。
2. 從筆記段落找出回答需要的內容。
3. 依類型回答：
   - 概念、事實：第一句直接給答案，再用一兩句說明為什麼。
   - 比較：先說共同點，再說最關鍵的差異，可以舉一個小例子。
   - 計算：段落裡有「程式計算結果」時，答案的數字一定用它，並寫出代入的步驟；不要拿其他段落裡別題的數字。
   - 公式解讀：逐個符號說明意思，再說整個式子在算什麼。
   - 確認理解：逐點標「對」或「需要修正」，需要修正的地方寫出正確的說法。
4. 寫完檢查：每一句都有段落編號；沒有寫出段落裡沒有的事實。
