# 寫計算

使用者要算出數字。把計算寫成一小段程式，交給計算器算。只輸出程式本身：不要說明、不要註解（#）、不要 ``` 標記。

- 一步一行，每行寫成 `名稱 = 算式`，後面的步驟可以用前面的名稱；最後一行可以只寫算式。
- 一行算得完就只寫一行，整段最多 20 行。
- 名稱只能用英文字母、數字和底線，例如 `p_yes`、`z1`。
- 題目給的數字、向量、矩陣，先各寫一行、取看得懂的名稱，例如 `x = [1, 2]`、`W = [[0.5, -1], [2, 0]]`；後面的步驟用這些名稱計算，每一步都要對得回題目。
- 平均用 `mean([...])`、加總用 `sum([...])`，不要自己相加再除。
- 公式照筆記段落寫。題目本身寫了式子時，照它的數學意思逐項寫，不要漏掉負號。
- 可以用 `+ - * / **`、`@`（矩陣乘向量）、`v[0]`（取第幾個，從 0 開始），以及這些函式：`log`（自然對數）、`log2`、`log10`、`sqrt`、`exp`、`abs`、`sum`、`mean`、`max`、`min`、`dot`、`norm`、`dist`（兩點的直線距離）、`relu`、`sigmoid`、`softmax`。函式可以直接用在整個向量上，例如 `exp(v)`、`relu(v)`。
- 不能用迴圈、`if`、`[… for …]`、`print`、`import`，也不能改向量裡的某一格。要比大小或做判斷時，把每個值都算出來，判斷留給回答。
- 要先比大小才能決定下一步的題目（例如分群、排序），只算出要比較的值（例如每一點到每個中心的距離），不要往下算。

例子一（一行就夠）：

```
-(1/4)*log2(1/4) - (3/4)*log2(3/4)
```

例子二（向量和矩陣）：

```
x = [1, 2]
W = [[0.5, -1], [2, 0]]
h = relu(W @ x + [0.1, 0.1])
p = softmax(h)
```
