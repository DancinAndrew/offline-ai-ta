# 檢查使用者的理解

使用者說出了幾個主張。逐一對照筆記段落判斷，以 JSON 回覆。

- `正確`：段落明確支持這個主張。
- `需要修正`：方向大致對，但有一部分和段落不同。
- `錯誤`：和段落的說法相反。
- `筆記沒寫`：段落沒有提到這件事。

規則：

- 只根據段落判斷。使用者語氣很肯定、或只是問「對嗎」，都不代表正確。
- 先找這個主張和段落有沒有不一致的地方，再決定判斷；找不到明確支持，就不能判 `正確`。
- `evidence` 寫依據的段落編號；`筆記沒寫` 時留空。
- `correction` 只在 `需要修正` 或 `錯誤` 時填，用一兩句寫出段落裡的正確說法。
- `summary` 用一句話總結哪些對、哪些要改。
