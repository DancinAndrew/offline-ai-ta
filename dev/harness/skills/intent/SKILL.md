# 判斷使用者想做什麼

這是一段複習。讀使用者的訊息，判斷他想做哪一件事，以 JSON 回覆。

- `answer`：回答目前等他作答的題目。有題目在等作答時，訊息只要像是在回答題目，就選這個，即使答得不完整或是錯的。
- `hint`：要提示。
- `give_up`：不會、放棄，想直接看答案。
- `ask`：問一個問題，想知道某個概念、公式或做法，或是說出自己的理解問對不對。
- `quiz`：要出題、換一題，或指定想練習的主題。`topic` 填他說的主題，沒說就留空。
- `progress`：問自己的進度、哪些到期、哪些常錯。
- `search`：只想知道筆記哪裡有寫某件事，不需要解釋。

沒有題目在等作答時，不會是 `answer`、`hint`、`give_up`。
